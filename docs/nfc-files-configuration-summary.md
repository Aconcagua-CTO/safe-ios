# NFC Configuration Files Summary

## Overview

This document lists all files that configure NFC capability in the iOS app and their current state.

## Files That Configure NFC

### 1. Entitlements Files (PRIMARY CONFIGURATION)

**Purpose:** Define which NFC formats the app supports

**Files:**
- `Multisig/MultisigDebug.Development.entitlements` (Debug.Development build)
- `Multisig/Multisig_DEV.entitlements` (DEV build)
- `Multisig/Multisig_STAGING.entitlements` (STAGING build)
- `Multisig/Multisig_PROD.entitlements` (PROD build)

**Current Configuration:**
```xml
<key>com.apple.developer.nfc.readersession.formats</key>
<array>
    <string>NDEF</string>
    <string>TAG</string>
    <string>PACE</string>
</array>
```

**Status:** ✅ All files configured consistently  
**Missing:** ❌ ISO7816 format not included

**How They're Used:**
- Referenced in `Multisig.xcodeproj/project.pbxproj` via `CODE_SIGN_ENTITLEMENTS`
- Used during code signing to embed NFC entitlements into app
- Must match formats in provisioning profile

### 2. Info.plist

**File:** `Multisig/Info.plist`

**Purpose:** User-facing description of NFC usage

**Current Configuration:**
```xml
<key>NFCReaderUsageDescription</key>
<string>Boveda needs NFC to communicate with Tangem hardware wallets.</string>
```

**Status:** ✅ Present and correct

**How It's Used:**
- Required by iOS to show permission prompt
- Displayed to user when NFC is accessed
- Must be present for NFC to work

### 3. Apple Developer Portal - App ID

**Location:** https://developer.apple.com/account/resources/identifiers/list  
**App ID:** `com.manuelrm.bovedapp.dev.mainnet` (and staging/prod)

**Purpose:** Enables NFC capability for the App ID

**Current Configuration:**
- ✅ NFC Tag Reading capability: **ENABLED**
- ❌ Format configuration options: **NOT VISIBLE**

**Status:** ✅ Capability enabled  
**Note:** No format checkboxes or configuration options are visible

**How It's Used:**
- Enables NFC capability for the App ID
- Provisioning profiles include NFC formats based on App ID configuration
- Formats might be auto-included when NFC Tag Reading is enabled

### 4. Xcode Project File

**File:** `Multisig.xcodeproj/project.pbxproj`

**Purpose:** References entitlements files and build configuration

**Current Configuration:**
- ✅ Entitlements files referenced correctly
- ✅ `CODE_SIGN_ENTITLEMENTS` points to correct files
- ❌ No `SystemCapabilities` found (NFC managed via entitlements)

**Status:** ✅ Entitlements correctly referenced  
**Note:** NFC capability is NOT configured via Xcode's capability system - managed entirely through entitlements files

**Relevant Sections:**


## Configuration Flow

```
1. Apple Developer Portal (App ID)
   └─> Enables NFC Tag Reading capability
       └─> (Formats might be auto-included or configured via entitlements)

2. Entitlements Files
   └─> Define NFC formats: NDEF, TAG, PACE
       └─> Referenced by Xcode project

3. Xcode Project
   └─> References entitlements files
       └─> Uses during build

4. Provisioning Profile
   └─> Generated based on App ID
       └─> Should include NFC formats
           └─> Must match entitlements file

5. Code Signing
   └─> Embeds entitlements into app
       └─> Uses entitlements file

6. Signed App
   └─> Contains NFC entitlements
       └─> Used by CoreNFC at runtime
```
