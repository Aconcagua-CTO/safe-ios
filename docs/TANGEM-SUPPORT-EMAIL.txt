  • config.linkedTerminal = true

ROOT CAUSE INVESTIGATION

We reviewed the Tangem SDK source code and found a firmware version check in SignCommand.swift (lines 254-260):

    private func retrieveTerminalKeys(from environment: SessionEnvironment) -> KeyPair? {
        guard let card = environment.card,
              card.settings.isLinkedTerminalEnabled,
              card.firmwareVersion < .hdWalletAvailable else {
                  return nil  // ← Blocks firmware >= 4.52
              }
        
        return environment.terminalKeys
    }

This check prevents terminal keys from being sent to HD wallet cards (firmware >= 4.52).

ANALYSIS

Two-Layer Restriction:

1. SDK Layer (Software):
   • Check: card.firmwareVersion < .hdWalletAvailable
   • Effect: Prevents sending terminal keys for firmware >= 4.52
   • Status: ✅ Successfully bypassed via binary patch

2. Card Firmware Layer (Hardware):
   • Card receives terminal keys ✅
   • Card has SkipSecurityDelayIfValidatedByLinkedTerminal setting ✅
   • Card REFUSES to store link (TAG_IsLinked stays 00) ❌
   • Card enforces full delay on every signature ❌
   • Status: ❌ Blocking linked terminal for HD wallets

Conclusion: Card firmware has its own restriction preventing HD wallet cards from accepting terminal links, independent of SDK.
